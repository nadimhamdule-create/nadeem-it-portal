#014Scheduled PowerShell script failureIssue-specific

What is this?

PowerShell script fails only in Task Scheduler/noninteractive context.

Common causes

  • Run-as account
  • Working directory
  • Profile/module/path
  • UNC credentials
  • Quoting/exit code

Detailed troubleshooting

Step 1 — Reproduce 'Scheduled PowerShell script failure' and capture the exact error, scope, timestamp and last known-good time.
Step 2 — Task Scheduler > History/Last Run Result: record exact code/time.
Step 3 — Use powershell.exe/pwsh.exe -NoProfile -File with full paths and correct Run-as account; mapped drives do not exist noninteractive.
Step 4 — Add transcript/ErrorAction Stop, run on demand and confirm 0x0 plus expected output.

Useful commands

schtasks /query /tn "<task>" /v /fo list
