#001Outlook cannot connectIssue-specific

What is this?

Outlook cannot connect is a Microsoft 365 incident. The checks below are specific to this symptom rather than a generic Microsoft 365 checklist.

Common causes

  • Exchange Online/service incident
  • Autodiscover/DNS issue
  • Corrupt Outlook profile or cached credentials
  • Network/proxy/TLS block
  • Office authentication token issue

Detailed troubleshooting

Step 1 — Reproduce 'Outlook cannot connect' and capture the exact error, scope, timestamp and last known-good time.
Step 2 — Admin Center > Health > Service health: check Exchange Online incident.
Step 3 — Test Outlook on the web. OWA works = desktop/profile/token; OWA fails = account/service/mailbox.
Step 4 — Outlook Ctrl+right-click tray > Test Email AutoConfiguration; verify Autodiscover, HTTPS 443 and then test a clean Outlook profile.

Useful commands

nslookup autodiscover.<domain> Test-NetConnection outlook.office365.com -Port 443

Verify resolution

Repeat the original 'Outlook cannot connect' workflow. Confirm success from the user side and confirm the corresponding service/event/audit log no longer records the same failure.
#002Outlook password promptIssue-specific
