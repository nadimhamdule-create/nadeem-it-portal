#001Windows boot failureIssue-specific

What is this?

Windows OS/application/service/security issue requiring evidence-based isolation.

Common causes

  • Service/process state
  • Permissions/security control
  • Corrupt app/system files
  • Recent configuration/update
  • User profile/driver conflict

Detailed troubleshooting

Step 1 — Reproduce 'Windows boot failure' and capture the exact error, scope, timestamp and last known-good time.
Step 2 — WinRE > Troubleshoot > Advanced options > Startup Repair. Record the result.
Step 3 — Try Startup Settings > Safe Mode. If Safe Mode works, inspect recent drivers/services/updates.
Step 4 — Check OS disk and System log; use BCD repair only when the error specifically points to boot configuration.

Useful commands

bcdedit chkdsk C: /scan sfc /scannow

Verify resolution

#003Blue screen BSODIssue-specific

What is this?

Windows kernel bugcheck/BSOD that may create a memory dump.

Common causes

  • Driver fault
  • RAM/storage hardware
  • Firmware/BIOS
  • Security/filter driver
  • Recent update/hardware change

Detailed troubleshooting

Step 1 — Reproduce 'Blue screen BSOD' and capture the exact error, scope, timestamp and last known-good time.
Step 2 — Record stop code and preserve C:\Windows\Minidump.
Step 3 — Reliability Monitor + System log: correlate BugCheck/WHEA/Disk events with the crash time.
Step 4 — Open dump in WinDbg and run !analyze -v; investigate the implicated driver/hardware instead of reinstalling blindly.

#009RDP not workingIssue-specific

What is this?

Remote Desktop connectivity or authentication issue between a client and Windows target.

Common causes

  • TCP 3389 blocked/listener missing
  • Remote Desktop disabled/GPO
  • TermService or NLA/CredSSP issue
  • User-rights problem
  • DNS/VPN/routing issue

Detailed troubleshooting

Step 1 — Reproduce 'RDP not working' and capture the exact error, scope, timestamp and last known-good time.
Step 2 — Client: Resolve-DnsName <server> then Test-NetConnection <server> -Port 3389.
Step 3 — Target: Settings > System > Remote Desktop; verify enabled. Then Get-Service TermService and qwinsta.
Step 4 — Firewall Advanced Security > Remote Desktop TCP-In; then check Remote Desktop Users/GPO and TerminalServices/Security logs.

Useful commands

Resolve-DnsName <server> Test-NetConnection <server> -Port 3389 Get-Service TermService qwinsta
